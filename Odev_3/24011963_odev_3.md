# Python Temel Konuları

## 1. Data Types (Veri Tipleri)

Python'da değişkenler, program içerisinde kullanacağımız verileri saklamak için kullanılır. Her değişkenin tuttuğu verinin bir tipi vardır. Python'da en sık kullanılan temel veri tipleri şunlardır:

- **int:** Tam sayıları tutar. Örneğin `10`, `25`, `-5`.
- **float:** Ondalıklı sayıları tutar. Örneğin `3.14`, `10.5`.
- **str:** Metinleri ve karakterleri tutar. Örneğin `"Merhaba"`.
- **bool:** Doğru veya yanlış değerlerini tutar (`True`, `False`).
- **list:** Birden fazla veriyi sıralı şekilde saklar. İçerisindeki elemanlar değiştirilebilir.
- **tuple:** Birden fazla veriyi sıralı şekilde saklar ancak elemanları değiştirilemez.
- **dict:** Verileri anahtar-değer (key-value) şeklinde saklar.
- **set:** Tekrarlanan elemanları saklamaz ve benzersiz değerlerden oluşur.

Örnek:

```python
isim = "Ahmet"
yas = 20
boy = 1.78
ogrenci_mi = True

notlar = [80, 90, 75]
ogrenci = {"isim": "Ahmet", "yas": 20}
```

Python'da `type()` fonksiyonu kullanılarak bir değişkenin veri tipi öğrenilebilir.

```python
print(type(yas))  # <class 'int'>
print(type(isim)) # <class 'str'>
```

## 2. Conditionals (Koşullu İfadeler)

Koşullu ifadeler, programın belirli durumlara göre farklı işlemler yapmasını sağlar. Python'da bunun için `if`, `elif` ve `else` kullanılır.

- **if:** Belirtilen koşul doğruysa çalışır.
- **elif:** İlk koşul yanlış olduğunda başka bir koşulu kontrol eder.
- **else:** Önceki koşulların hiçbiri doğru değilse çalışır.

Örnek:

```python
batarya = 25

if batarya > 70:
    print("Batarya seviyesi iyi.")
elif batarya > 30:
    print("Batarya seviyesi orta.")
else:
    print("Batarya seviyesi düşük!")
```

Bu örnekte batarya seviyesi kontrol edilir. Değer 70'ten büyükse ilk mesaj, 30'dan büyükse ikinci mesaj, diğer durumlarda ise son mesaj ekrana yazdırılır.

## 3. Loops (Döngüler)

Döngüler, aynı işlemi birden fazla kez gerçekleştirmek için kullanılır. Python'da en çok kullanılan döngüler `for` ve `while` döngüleridir.

**For döngüsü:** Genellikle bir liste veya belirli bir aralık içerisindeki elemanları sırayla işlemek için kullanılır.

Örnek:

```python
for sayi in range(1, 6):
    print(sayi)
```

Bu kod 1'den 5'e kadar olan sayıları ekrana yazdırır.

**While döngüsü:** Belirtilen koşul doğru olduğu sürece çalışmaya devam eder.

Örnek:

```python
batarya = 100

while batarya > 0:
    print("Batarya:", batarya)
    batarya -= 25
```

Bu örnekte batarya değeri her döngüde 25 azaltılır. Değer sıfıra ulaştığında döngü sona erer.

## 4. Functions (Fonksiyonlar)

Fonksiyonlar, belirli bir görevi yerine getirmek için yazılan ve ihtiyaç duyulduğunda tekrar kullanılabilen kod bloklarıdır. Kod tekrarını azaltır ve programın daha düzenli olmasını sağlar.

Python'da fonksiyon tanımlamak için `def` anahtar kelimesi kullanılır. Fonksiyonlar parametre alabilir ve `return` ile sonuç döndürebilir.

Örnek:

```python
def hiz_hesapla(yol, zaman):
    hiz = yol / zaman
    return hiz

sonuc = hiz_hesapla(100, 2)
print("Ortalama hız:", sonuc)
```

Bu örnekte fonksiyon, alınan yol ve zaman bilgilerini kullanarak ortalama hızı hesaplar. Sonucu `return` ile geri döndürür.

## 5. Classes (Sınıflar)

Sınıflar, gerçek hayattaki varlıkları veya nesneleri program içerisinde temsil etmek için kullanılır. Bir sınıfın içerisinde özellikler (attributes) ve fonksiyonlar (methods) bulunabilir. Sınıftan oluşturulan örneklere ise nesne (object) denir.

Python'da sınıf tanımlamak için `class` anahtar kelimesi kullanılır. `__init__()` metodu, nesne oluşturulduğunda başlangıç değerlerini ayarlamak için kullanılır. `self` ise oluşturulan nesnenin kendi özelliklerine ve metotlarına erişmesini sağlar.

Örnek:

```python
class IHA:
    def __init__(self, model, batarya):
        self.model = model
        self.batarya = batarya

    def bilgileri_goster(self):
        print("Model:", self.model)
        print("Batarya:", self.batarya)

iha1 = IHA("Pixhawk", 85)
iha1.bilgileri_goster()
```

Bu örnekte `IHA` adında bir sınıf oluşturulmuştur. Model ve batarya bilgileri nesneye ait özelliklerdir. Daha sonra bu sınıftan `iha1` adında bir nesne oluşturularak bilgileri ekrana yazdırılmıştır.
